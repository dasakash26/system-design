# High Level Design (HLD)

Study notes and architectural case studies for building scalable, highly available, and fault-tolerant distributed systems.

---

## Core Topics

- **Scalability**: Vertical vs. horizontal scaling, load balancing, API gateways.
- **Databases**: Replication, sharding, partitioning, SQL vs. NoSQL, consistency models (CAP theorem).
- **Caching**: Cache invalidation strategies, eviction policies, distributed caching (Redis, Memcached).
- **Messaging & Event-Driven Systems**: Message queues (RabbitMQ, Kafka), pub/sub models.
- **Resiliency**: Rate limiting, circuit breakers, retries, and backoff patterns.
